## About Core Module

Core Module contains all the necessary functionalities for build up a new Laravel application.

Core Module built-in features:

-   Users, multi level Roles, Permissions and licenses
-   Verify new users via email
-   New user registration endpoint and quick terminal command
-   Automatic Last user login timestamp
-   More interactive model creation and modifications via command
-   Redis cache manager tagged by entities, users and roles
-   Elastic Search entities automatic indexing
-   Enhanced Swagger doc generation
-   Translations check utility
-   Additional helpers to enhance modules operation
-   App settings and configurable Cron-Jobs on db tables
-   Automatic localization set on user request
-   Preview middleware for pending models approvals and multiuser approval system
-   Models versioning functionalities, with rollback functionalities
-   Dynamic entities for non mapped models
-   Multi entities and connections crud endpoints with standardized requests parameters
-   Multi entities and connections exposed interactive grid endpoints
-   Strongly validated requests for Core routes
-   Default common Response Formatter
-   Common columns migration helpers
-   Common Cache, Approvals, Observers, Validations, Validity period traits to share main functionalities to models
